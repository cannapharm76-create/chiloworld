# Chilo Exotics website

Static marketing/B2B enquiry site for Chilo Exotics.

## Deploy
Upload `index.html`, `styles.css`, and `script.js` to any static host such as Netlify, Vercel, Cloudflare Pages, GitHub Pages, or your own web server.

## Important
This build intentionally has **no ecommerce/cart/online cannabis ordering**. It uses a direct wholesale enquiry form because Thailand's current cannabis framework regulates cannabis flower and restricts electronic sales.

Before launch:
- Replace `hello@chiloexotics.com` with the real business email.
- Add the real company/licence information only after verification.
- Add a real privacy policy and terms.
- Have Thai counsel/compliance staff review all claims, product descriptions, advertising, and enquiry flow.
- Replace the placeholder visual panels with licensed brand photography if desired.

The visual direction is an original adaptation of the supplied dark financial-platform design analysis: near-black surfaces, a single yellow/gold action accent, compact radii, dense cards, and strong numerical typography.
